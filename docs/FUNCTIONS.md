# Function reference

| Function | Responsibility |
| --- | --- |
| `Start` | Disables IRQs, initializes VIC/screen/charset/colour RAM/state/SID, installs the RAM IRQ vector, then enables raster IRQs. |
| `IRQ_Handler` | Acknowledges the VIC IRQ, renders the timed raster-bar region, restores the normal background, applies the scroller split, ticks the SID, and chains to `$EA31`. |
| `DrawBannerCharGfx` | Writes the two title strings and their shadow rows using the program charset. |
| `CenterPrintRow` | Centers a null-terminated string; it rejects rows outside the 25-row screen and limits output to 40 characters. |
| `ColorCenteredRowGrey` | Colours the centered banner/shadow row while preserving the caller's row argument. |
| `Scroller_Tick` | Advances the fine-scroll phase and shifts/refills the bottom text row on wrap. |
| `SID_Init` | Clears all SID registers, then configures SID voice 1 for a pulse-wave arpeggio. |
| `SID_Tick` | Loads one note from the bounded arpeggio sequence and wraps safely at its declared length. |
| `ClearScreen` / `ClearColor` | Reset screen RAM and colour RAM before content is drawn. |

The checked-in charset is generated by `scripts/generate_charset.py`; the
verifier reproduces it byte-for-byte before accepting a build.
